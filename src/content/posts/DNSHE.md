## 关于 DNSHE

DNSHE 提供以下核心服务：

- **免费域名注册**：在 DNSHE 运营的公共后缀下注册免费二级域名
- **全量 DNS 记录管理**：支持 A、AAAA、CNAME、MX、TXT、NS、SRV、CAA 等记录类型
- **仪表盘与 API 管理**：支持通过网页后台或 REST API 自动化管理域名和 DNS 记录
- **Anycast DNS 加速**：全球分布式解析，响应迅速
- **Cloudflare 无缝托管**：支持将域名一键托管至 Cloudflare，享受 CDN 加速、免费 SSL、WAF 防护等完整功能

目前开放注册的后缀包括 `.de5.net`、`.us.ci`、`.cc.cd`、`.bot.cd`、`.ccwu.cc` 等多个选择。注册全程无需绑定信用卡，无隐形收费。
